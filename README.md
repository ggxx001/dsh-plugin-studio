# 插件会话工坊（Plugin Sessions）

给**已安装插件**开一个带上下文的修改会话：在「设置 → 插件」里点开 **会话工坊** 标签页，点任意插件，就会带着它的源码目录、插件行和补丁路径开一个会话；之后一直在同一个会话里继续改它。

自己写过的插件（`link:` / `file:` 安装在 Profile 里、有源码目录）会先按会话标题匹配到**当时写它的那条会话**：卡片直接显示「继续编辑」，点一下就回到原会话继续，不会新建。

## 它做什么

- 列出当前 Profile 的已安装插件，支持按名称、包名、描述、插件行搜索。
- **按来源区分**：每张卡片带来源标签，并可用顶部筛选条切换——
  - **本地开发**：`link:` / `file:` 装进 Profile、有可编辑源码目录的插件；
  - **下载安装**：从注册表装进 Profile 的插件（`dsh-pet`、皮肤等），源码在 Profile 的 `node_modules` 里，不直接改；
  - **系统内置**：随安装包发布的插件（实验性插件、内置市场等）。
  - 列表按「本地开发 → 下载安装 → 系统内置」排序，并用左侧色条区分来源。
- 每个插件一张卡片，点开是一个 **会话窗口**：
  - 自动解析源码目录（`link:` / `file:` 安装的插件）与 `cordis.patch.yml` 路径；
  - 一段可自由编辑的「开场说明」，写明插件包名、状态、插件行、源码与 Profile；
  - 点「创建会话」，会创建会话、发送说明、把会话标题改成 `改插件 · <插件名>`，并跳到对话。
- 自己写过的插件会按标题匹配已有会话（如「彻底卸载」↔「浏览器插件彻底卸载工具」），卡片显示「关联会话 · 标题 · 时间」与 **继续编辑**；窗口里也会列出最多 5 条候选。
- **实时同步**：每 5 秒（以及窗口重新获得焦点时）同步一次插件库，新安装、停用、卸载的插件会自动出现在列表里；右上角显示「实时同步」，也可以手动刷新。
- **还没安装的新插件**：扫描 `<工作区>/plugins` 下不在 Profile 里的目录，以「未安装」列出；点「安装并创建会话」会开一个会话，让 Agent 先安装这个目录再继续改。
- 会话记在浏览器存储里（localStorage + Cookie 兜底）：卡片上显示最近会话，点卡片直接回到它继续改。
- 记录丢失也能找回：卡片会按 `改插件 · <插件名>` 的会话标题在会话列表里匹配最近一次修改会话。
- 会话失效（被删除/归档）会标记出来，下一次点开会自动重建。

## 为什么用会话

插件修改需要读源码、改文件、重新安装，还要记住上一轮改了什么。会话就是这条工作线：开场说明给 Agent 一个准确的起点，后续每轮要求都留在同一个上下文里，插件和它的历史不会散落。

## 开场说明让 Agent 先做什么

1. 读 `package.json`、`cordis.patch.yml`、`index.js`、`client.js`，说明插件现在的结构与 Host/Client 分工；
2. 指出这次修改最可能落到哪里（插件行 id、插槽、组件、配置）；
3. 先问你要改什么，**不**直接动文件。

内置插件（源码随安装包）没有 Profile 源码目录，说明会改成「先说明覆盖/配置的可行路径」。

## 安装

```bash
dsh plugin --profile desktop add link:D:\deepseek\plugins\dsh-plugin-studio
```

也可以由 `plugin_manager` 的 `install_bundle` 安装本目录。安装后打开「设置 → 插件 → 会话工坊」。

## 边界

- 本插件只负责**开会话**与解析路径，不改插件文件；修改由该会话里的 Agent 用普通文件工具和 `plugin_manager` 完成。
- 源码目录对 Profile 里以 `link:` / `file:` 记录的依赖有效；注册表安装的插件会给出 Profile `node_modules` 里的副本路径，并在说明里按「复制到工作区 + link / 新 bundle」处理；内置插件的文件在安装包里，只能覆盖或配置，不能原地改。
- 标题匹配是启发式：它会按标题里的共同片段（如「彻底卸载」）找会话，近似标题的会话会一起列为候选；点之前看一眼标题和时间即可确认。
- 未安装目录的检测依赖桌面端的目录浏览接口；拿不到时这一栏自动隐藏，已安装插件列表不受影响。
- 会话记录是界面侧的辅助索引，不是事实来源；会话本身始终以 Host 的会话日志为准。
- 读路径的 Host 路由是只读的：`/api/plugin-studio/facts` 只返回 Profile 目录、依赖 spec、源码目录、安装副本目录与补丁路径。
